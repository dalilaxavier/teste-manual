# 🧪 Projeto - AgendaLab QA

Projeto de testes manuais funcionais realizados na aplicação AgendaLab, com foco na validação de requisitos e dos principais fluxos funcionais do sistema.

Os testes contemplaram fluxos positivos, negativos e alternativos, além da execução de testes exploratórios e identificação e documentação de defeitos.

## 🔗 Aplicação testada

[AgendaLab QA](https://agendalabqa.vercel.app/)


## 🎯 Objetivos

Este projeto tem como objetivo:

- Analisar os requisitos especificados na documentação. 
- Validar os fluxos principais do sistema.
- Aplicar técnicas e boas práticas de QA.
- Elaborar cenários e casos de teste.
- Realizar testes exploratórios.
- Analisar o tempo de carregamento em cenários específicos utilizando o DevTools.
- Identificar, documentar e reportar defeitos encontrados durante os testes.


## 📋 Escopo de Testes

**Dentro do Escopo:**

- Autenticação de Usuários.
- Dashboard.
- Catálogo de Serviços.
- Novo agendamento.
- Listagem de Meus Agendamentos.
- Filtro de Agendamento.
- Cancelamento de Agendamento.
- Reagendamento.
- Navegação de Layout.
- Reset de Dados de Teste.
- Persistência de Dados.
- Validação de Disponibilidade de Horário.
- Acessibilidade e Responsividade.

---

**Fora do Escopo:**

- Página de Requisitos do Sistema.


## ✅ Técnica de Testes Aplicadas
