# RF003 - Catálogo de Serviços

## Cenário de Teste 01 (C001): Visualizar serviços cadastrados

### CT001 - Visualizar serviços cadastrados com suas propriedades

Requisito: 
1. RF003.1

Descrição: Verificar se o sistema exibe os serviços cadastrados contendo nome, categoria, duração e profissionais vinculados. 

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário esteja na página Serviços.

Passos para execução:
1. Verificar os serviços apresentados.

Resultado esperado: O sistema deve exibir os seis serviços cadastrados contendo nome, categoria, duração e profissionais vinculados.

Resultado obtido: O sistema exibiu os seis serviços cadastrados, contendo nome, categoria, duração e profissionais vinculados.

Status: Passou ✅

## Cenário de Teste 03 (C003): Redirecionamento de usuário

### CT003 - Redirecionamento de usuário para o formulário

Requisito: 
1. RF003.3

Descrição: Verificar se o usuário é redirecionado para o formulário ao clicar no botão "Agendar". 

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário esteja na página Serviços.

Passos para execução:
1. Selecionar um Serviço. 
2. Clicar em "Agendar". 

Resultado esperado: O sistema deve redirecionar o usuário para o formulário com o serviço pré-selecionado. 

Resultado obtido: O sistema redirecionou o usuário para o formulário com o serviço pré-selecionado corretamente.

Status: Passou ✅
