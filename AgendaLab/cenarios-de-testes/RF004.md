## Cenário de Teste 03 (C003): Agendamento com dados inválidos

### CT009 - Registrar agendamento com telefone inválido

Requisito: 
1. RF004.2

Descrição: Verificar o comportamento do sistema ao informar caracteres não permitidos no campo telefone.

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário esteja na página do formulário de agendamento. 

Passos para execução:
1. Informar nome válido.
2. Informar caracteres não permitidos no campo telefone.
3. Preencher os demais campos com dados válidos.
4. Clicar em "Confirmar Agendamento".

Resultado esperado: O sistema deve rejeitar o telefone informado, pois o campo aceita apenas dígitos, parênteses, espaços e hífens, impedindo o registro do agendamento.

Resultado obtido: O sistema rejeitou o telefone informado, impediu o registro do agendamento e apresentou a mensagem: “Telefone inválido. Use apenas números, parênteses, espaços e hífens.”

Status: Passou ✅
