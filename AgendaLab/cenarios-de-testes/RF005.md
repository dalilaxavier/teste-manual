# RF005 - Listagem de Meus Agendamentos

## Cenário de Teste 01 (C001): Listagem dos agendamentos com sucesso

### CT001 - Agendamentos exibidos em cards 

Requisito: 
1. RF005.1

Descrição: Verificar se o sistema exibe os agendamentos do usuário em cards.

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário esteja na página de Dashboard.
3. Usuário deve possuir agendamentos. 

Passos para execução:
1. Clicar em "Meus agendamentos".
2. Verificar a apresentação dos agendamentos.  

Resultado esperado: O sistema deve exibir os agendamentos em cards. 

Resultado obtido: O sistema exibiu os agendamentos em cards.

Status: Passou ✅
