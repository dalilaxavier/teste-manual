# RF007 - Cancelamento de Agendamento

## Cenário de Teste 01 (C001): Cancelar agendamento com sucesso

Requisito:
1. RF007.1

Descrição: Verificar se o sistema permite o cancelamento de agendamento com status CONFIRMADO com 2 horas de antecedência. 

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário esteja na página Meus Agendamentos.
3. Usuário deve possuir pelo menos um agendamento com status CONFIRMADO.

Passos para execução:
1. Selecionar a opção "Cancelar".

Resultado esperado: O sistema deve permitir que o usuário realize o cancelamento com sucesso.

Resultado obtido: O sistema permitiu o cancelamento do agendamento com sucesso.

Status: Passou ✅
