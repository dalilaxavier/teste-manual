# RF008 - Reagendamento

## Cenário de Teste 01 (C001): Apresentação de formulário

### CT001 - Apresentar formulário de reagendamento pré-preenchido

Requisito: 
1. RF008.1

Descrição: Verificar se sistema apresenta o formulário de reagendamento pré-preenchido. 

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário esteja na página Meus Agendamentos.
3. Usuário deve possuir pelo menos um agendamento com status CONFIRMADO.

Passos para execução:
1. Selecionar a opção "Reagendar".
2. Verificar se os dados atuais do agendamento estão pré-preenchidos no formulário.

Resultado esperado: O sistema deve apresentar um formulário de reagendamento pré-preenchido com os dados atuais do agendamento.

Resultado obtido: O sistema apresentou um formulário de reagendamento pré-preenchido com os dados atuais do agendamento.

Status: Passou ✅

## Cenário de Teste 02 (C002): Reagendamento com sucesso

### CT002 - Reagendar com dados válidos

Requisito: 
1. RF008.1
2. RF008.2

Descrição: Verificar se sistema permite o reagendamento de um serviço com sucesso.  

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário esteja na página Meus Agendamentos.
3. Usuário deve possuir pelo menos um agendamento com status CONFIRMADO.

Passos para execução:
1. Selecionar a opção "Reagendar".
2. Verificar se os dados atuais do agendamento estão pré-preenchidos.
3. Selecionar uma data válida.
4. Selecionar um horário válido.
5. Clicar em "Confirmar Reagendamento". 
6. Verificar a mensagem de confirmação apresentada.
7. Clicar em "Ver Meus Agendamentos".

Resultado esperado: O sistema deve confirmar o reagendamento com sucesso e atualizar o agendamento com a nova data e horário, mantendo o status CONFIRMADO.

Resultado obtido: O sistema realizou o reagendamento com sucesso exibindo a mensagem "Reagendado com Sucesso!". Ao clicar em Meus Agendamentos, foi possível identificar o reagendamento com status CONFIRMADO.

Status: Passou ✅

### CT003 - Persistência da data e horário reagendados no localStorage

Requisito: 
1. RF008.1
2. RF008.2
3. RF008.3

Descrição: Verificar se a data e o horário selecionados no reagendamento são persistidos corretamente no localStorage.

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário esteja na página Meus Agendamentos.
3. Usuário deve possuir pelo menos um agendamento com status CONFIRMADO.

Passos para execução:
1. Selecionar a opção "Reagendar".
2. Confirmar as informações apresentadas do formulário pré-preenchido. 
3. Selecionar uma data válida.
4. Selecionar um horário válido.
5. Clicar em "Confirmar Reagendamento". 
6. Confirmar a mensagem apresentada.
7. Clicar em "Ver Meus Agendamentos".
8. Acessar o DevTools do navegador.
9. Acessar a sessão Application.
10. Acessar Local Storage.
11. Verificar os dados do agendamento armazenados. 

Resultado esperado: O sistema deve armazenar no localStorage a nova data e o novo horário do agendamento.

Resultado obtido: O sistema armazenou no localStorage a nova data e horário de agendamento.

Status: Passou ✅

## Cenário de Teste 03 (C003): Cancelamento de reagendamento

### CT004 - Cancelar o reagendamento

Requisito: 
1. RF008.4

Descrição: Verificar se o sistema permite cancelar a operação de reagendamento sem alterar os dados do agendamento.

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário esteja na página Meus Agendamentos.
3. Usuário deve possuir pelo menos um agendamento com status CONFIRMADO.

Passos para execução:
1. Selecionar a opção "Reagendar".
2. Confirmar as informações apresentadas.
3. Clicar em "Cancelar".

Resultado esperado: O sistema deve retornar para a página Meus Agendamentos sem alterar o agendamento. 

Resultado obtido: O sistema permitiu retornar para a página Meus Agendamentos sem alterar o agendamento.  

Status: Passou ✅
