## Cenário de Teste 01 (C001): Acesso aos links do menu com sucesso

### CT001 - Acessar a página do Dashboard

Requisito: 
1. RF010.1 

Descrição: Verificar se o menu permite o acesso direto ao Dashboard.

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário deve estar em uma página diferente da Dashboard.

Passos para execução:
1. Clicar no ícone sanduíche localizado ao lado esquerdo.
2. Clicar em Dashboard.

Resultado esperado: O sistema deve redirecionar o usuário para a página de Dashboard. 

Resultado obtido: O sistema permitiu o redirecionamento do usuário para a página Dashboard corretamente.

## Cenário de Teste 03 (C003): Responsividade do layout

### CT008 - Responsividade do layout desktop

Requisito: 
1. RF010.3

Descrição: Verificar se o sistema apresenta layout adequado em resolução desktop.

Pré-condição:
1. Usuário autenticado no sistema.

Passos para execução:
1. Acessar o sistema em resolução desktop.
2. Navegar pelas principais páginas do sistema.
3. Verificar a disposição dos elementos na interface.
4. Verificar se os elementos permanecem visíveis e acessíveis.

Resultado esperado: O sistema deve apresentar layout adequado à resolução desktop, mantendo os elementos visíveis, organizados e acessíveis, sem sobreposição ou corte de conteúdo.

Resultado obtido: O sistema apresentou layout adequado à resolução desktop, mantendo todos os elementos visíveis e sem sobreposição ou cortes de conteúdo.

Status: Passou ✅

### CT009 - Responsividade do layout mobile

Requisito: 
1. RF010.3

Descrição: Verificar se o sistema apresenta layout responsivo em resolução mobile.
