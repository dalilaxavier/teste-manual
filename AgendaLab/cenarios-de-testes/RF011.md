# RF011 - Reset de Dados de Teste

## Cenário de Teste 01 (C001): Reset de dados com sucesso

### CT001 - Reset de dados do localStorage

Requisito: 
1. RF011.1 

Descrição: Verificar se, ao clicar em "Resetar Dados", os dados de agendamentos são removidos do localStorage. 

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário deve possuir pelo menos um agendamento cadastrado.

Passos para execução:
1. Clicar em "Resetar Dados".
2. Acessar o DevTools do navegador. 
3. Acessar a sessão Application.
4. Acessar Local Storage.

Resultado esperado: Os dados dos agendamentos devem ser removidos do localStorage.

Resultado obtido: O sistema removeu os dados dos agendamentos do localStorage.

Status: Passou ✅

### CT002 - Reset dos dados de demonstração

Requisito: 
1. RF011.2

Descrição: Verificar se, ao clicar no botão de reset, os dados iniciais são restaurados. 

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário deve possuir pelo menos um agendamento cadastrado.

Passos para execução:
1. Clicar em "Resetar Dados".
2. Observar o comportamento do sistema.

Resultado esperado: O sistema deve retornar ao estado inicial de demonstração.

Resultado obtido: Após clicar em "Resetar Dados", os agendamentos realizados continuaram sendo exibidos na interface. O estado inicial de demonstração somente foi apresentado após atualizar a página.

Status: Falhou ❌

### CT003 - Confirmar mensagem ao resetar dados

Requisito:

Descrição: Verificar se uma mensagem de sucesso é apresentada após o reset.

Pré-condição:
1. Usuário autenticado no sistema.

Passos para execução:

Resultado esperado: O sistema deve apresentar uma mensagem de sucesso após a conclusão do reset dos dados.

Resultado obtido: O sistema apresentou a mensagem de sucesso: ✅ Dados resetados com sucesso! Os agendamentos de demonstração foram restaurados.
