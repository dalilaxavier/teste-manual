# RF012 - Persistência de Dados

## Cenário de Teste 01 (C001): Persistência de dados após mudanças

### CT001 - Persistência de dados no localStorage após cancelamento de agendamento

Requisito: 
1. RF012.1 

Descrição: Verificar se, após o cancelamento de um agendamento, a alteração persiste no localStorage.

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário deve possuir pelo menos um agendamento cadastrado.

Passos para execução:
1. Acessar a página Meus Agendamentos.
2. Clicar em "Cancelar".
3. Acessar o DevTools do navegador. 
4. Acessar a sessão Application.
5. Acessar Local Storage.
6. Verificar se o status do agendamento foi atualizado no localStorage.

Resultado esperado: A alteração realizada no agendamento deve ser persistida imediatamente no localStorage.

Resultado obtido: A alteração no agendamento persistiu imediatamente no localStorage.

Status: Passou ✅

### CT002 - Persistência de dados no localStorage após reagendamento

Requisito: 
1. RF012.1 

Descrição: Verificar se, após um reagendamento, a alteração persiste no localStorage.

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário deve possuir pelo menos um agendamento cadastrado.

Passos para execução:
1. Acessar a página Meus Agendamentos.
2. Clicar em "Reagendar".
3. Selecionar uma Data.
4. Selecionar um horário.
5. Clicar em "Confirmar Reagendamento". 
6. Acessar o DevTools do navegador. 
7. Acessar a sessão Application.
8. Acessar Local Storage.
9. Verificar se a nova data e o novo horário foram persistidos no localStorage.

Resultado esperado: As alterações realizadas no agendamento devem ser persistidas imediatamente no localStorage.

Resultado obtido: As alterações realizadas no agendamento persistiram imediatamente no localStorage.

Status: Passou ✅

## Cenário de Teste 02 (C002): Recuperar os dados após recarregar

### CT003 - Recuperar dados persistidos ao recarregar a página

Requisito: 
1. RF012.2

Descrição: Verificar se ao recarregar a página os dados persistidos no localStorage serão recuperados corretamente.

Pré-condição:
1. Usuário autenticado no sistema.

Passos para execução:
1. Acessar a página Meus Agendamentos.
2. Realizar um novo agendamento.
3. Recarregar a página.
4. Verificar os agendamentos apresentados.

Resultado esperado: Após o recarregamento da página, o sistema deve recuperar e exibir corretamente os dados dos agendamentos persistidos no localStorage.

Resultado obtido: Após o recarregamento, o sistema recuperou e exibiu corretamente o agendamento realizado antes do recarregamento. 

Status: Passou ✅

## Cenário de Teste 03 (C003): Integridade dos dados

### CT004 - Integridade dos dados serializados e desesserializados

Requisito: 
1. RF012.3

Descrição: Verificar se os dados permanecem íntegros após serem serializados para JSON e posteriormente desserializados pelo sistema. 

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário deve possuir pelo menos um agendamento cadastrado.

Passos para execução:
1. Acessar a página "Meus Agendamentos".
2. Identificar um agendamento.
3. Registrar os dados apresentados no agendamento.
4. Acessar o DevTools do navegador.
5. Acessar a sessão Application.
6. Acessar Local Storage.
7. Verificar os dados do agendamento armazenados no localStorage.
8. Recarregar a página.
9. Verificar os dados do agendamento apresentados na aplicação.
10. Comparar os dados apresentados antes e após o recarregamento.

Resultado esperado: Os dados do agendamento devem permanecer íntegros após a serialização e desserialização, mantendo os mesmos valores apresentados antes e após o recarregamento.

Resultado obtido: Os dados dos agendamentos permaneceram íntegros após a serialização e desserialização, mantendo os mesmos dados após recarregamento.

Status: Passou ✅
