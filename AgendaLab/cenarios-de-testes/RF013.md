# RF013 - Validação de Disponibilidade de Horário

## Cenário de Teste 01 (C001): Agendamento do profissional na data selecionada

### CT001 - Verificar agendamentos confirmados do profissional na data selecionada

Requisito: 
1. RF013.1 

Descrição: Verificar se o sistema considera os agendamentos CONFIRMADOS do profissional na data selecionada ao determinar os horários disponíveis.


Pré-condição:
1. Usuário autenticado no sistema.
2. Profissional possui pelo menos um agendamento com status CONFIRMADO em determinada data e horário.

Passos para execução:
1. Acessar Novo Agendamento.
2. Selecionar o profissional que possui o agendamento.
3. Selecionar a mesma data do agendamento confirmado.
4. Verificar os horários disponíveis.

Resultado esperado: O sistema deve considerar o agendamento confirmado do profissional na data selecionada ao determinar os horários disponíveis.

Resultado obtido: O sistema considerou o agendamento com status CONFIRMADO associado ao profissional na data selecionada.

Status: Passou ✅

## Cenário de Teste 02 (C002): Indicação de horário indisponível

### CT002 - Visualizar horário indisponível

Requisito: 
1. RF013.2 

Descrição: Verificar se o sistema indica visualmente os horários indisponíveis.

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário possui pelo menos um agendamento CONFIRMADO com o profissional selecionado.

Passos para execução:
1. Clicar em Novo Agendamento.
2. Selecionar um serviço.
3. Selecionar o profissional que tem serviço com status CONFIRMADO.
4. Selecionar a data do agendamento confirmado.
5. Verificar os horários apresentados.

Resultado esperado: O sistema deve indicar visualmente como indisponíveis os horários que possuem agendamentos CONFIRMADOS para a profissional selecionada na data escolhida.

Resultado obtido: O sistema exibiu corretamente os horários disponíveis e indicou visualmente como indisponível o horário que possuía agendamento com status CONFIRMADO para o profissional selecionado.

Status: Passou ✅

## Cenário de Teste 03 (C003): Agendamento em horário indisponível

### CT003 - Agendar em horário indisponível

Requisito: 
1. RF013.3 

Descrição: Validar se o sistema impede o agendamento em horário indisponível. 

Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário possui pelo menos um agendamento CONFIRMADO com o profissional selecionado.

Passos para execução:
1. Acessar "Novo Agendamento".
2. Selecionar um serviço .
3. Selecionar o profissional que possui o agendamento CONFIRMADO.
4. Selecionar a data do agendamento confirmado.
5. Tentar selecionar o horário indicado visualmente como indisponível.

Resultado esperado: O sistema não deve permitir a criação de agendamento em horário indisponível.

Resultado obtido: O sistema não permitiu selecionar o horário indicado como indisponível e, consequentemente, não permitiu a criação do agendamento nesse horário.

Status: Passou ✅
