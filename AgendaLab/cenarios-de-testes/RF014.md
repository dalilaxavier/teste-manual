# RF014 - Acessibilidade e Responsividade

## Cenário de Teste 01 (C001): Elementos interativos com ARIA

### CT001 - Verificar os principais elementos com os atributos ARIA

Requisito: 
1. RF014.1 

Descrição: Verificar se o sistema possui os atributos ARIA nos principais elementos.


Pré-condição:
1. Usuário autenticado no sistema.

Passos para execução:
1. Acessar o DevTools do navegador. 
2. Acessar a sessão Elements.
3. Analisar os principais elementos interativos.

Resultado esperado: Os principais elementos interativos devem possuir os atributos ARIA necessários para sua identificação.

Resultado obtido: Os principais elementos interativos analisados possuem atributos ARIA compatíveis com sua identificação e interação.

Status: Passou ✅

## Cenário de Teste 02 (C002): Contraste necessário

### CT002 - Contraste entre texto e fundo

Requisito: 
1. RF014.2 

Descrição: Verificar se o sistema possui um contraste mínimo entre o texto e fundo.


Pré-condição:
1. Usuário autenticado no sistema.

Passos para execução:
1. Acessar o DevTools do navegador. 
2. Acessar a sessão Elements.
3. Identificar os principais elementos que contêm texto.
4. Identificar as cores do texto e do fundo.
5. Verificar a proporção de contraste apresentada pelo DevTools.
6. Comparar os valores encontrados com o mínimo de 4.5:1.

Resultado esperado: O contraste entre o texto e o fundo deve ser igual ou superior a 4.5:1.

Resultado obtido: A maioria dos elementos analisados apresentou contraste igual ou superior a 4.5:1. Entretanto, os textos "Agende um Serviço", "Gerencie seus agendamentos" e "Serviços", localizados nos atalhos do Dashboard, apresentaram contraste inferior ao mínimo estabelecido de 4.5:1.

Status: Falhou ❌

## Cenário de Teste 03 (C003): Layout funcional

### CT003 - Layout de tela de largura 320px 

Requisito: 
1. RF014.3

Descrição: Verificar se o sistema possui layout funcional em uma tela com 320px de largura. 


Pré-condição:
1. Usuário autenticado no sistema.

Passos para execução:
1. Acessar o sistema em resolução 320px de largura.
2. Navegar pelas principais páginas do sistema.
3. Verificar a disposição dos elementos na interface.
4. Verificar se os elementos permanecem visíveis e acessíveis.

Resultado esperado: O sistema deve apresentar layout adequado à resolução de 320px de largura, mantendo os elementos visíveis, organizados e acessíveis, sem sobreposição ou corte de conteúdo.

Resultado obtido: O sistema apresentou layout funcional em uma resolução de 320px de largura.

Status: Passou ✅


## Cenário de Teste 04 (C004): Navegação por teclado

### CT004 - Navegar por teclado

Requisito: 
1. RF014.4

Descrição: Verificar se o sistema permite a navegação por teclado nos formulários e botões de ação.


Pré-condição:
1. Usuário autenticado no sistema.
2. Usuário esteja na página de formulário.

Passos para execução:
1. Utilizar a tecla Tab para navegar entre os campos e elementos interativos.
2. Preencher os campos utilizando o teclado.
3. Utilizar Tab até alcançar os botões de ação.
4. Pressionar Enter para acionar o botão.
5. Observar o comportamento do sistema.


Resultado esperado: O sistema deve permitir a navegação pelos campos e elementos interativos utilizando a tecla Tab e a ativação dos botões de ação utilizando a tecla Enter.

Resultado obtido: O sistema permitiu a navegação pelos campos e elementos interativos utilizando a tecla Tab e a ativação dos botões de ação utilizando a tecla Enter. 

Status: Passou ✅
