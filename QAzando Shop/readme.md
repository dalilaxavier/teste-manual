# Portfólio de Testes - QAzando Shop

Este repositório contém o material referente ao projeto de testes do site **QAzando Shop**, incluindo o plano de testes exploratórios, relatório de bugs e o relatório final.

## Conteúdo da Pasta

- **Plano de Testes.md**  
  Documento detalhando os objetivos, critérios, charters e técnicas de teste utilizadas.

- **Relatório de Bugs.md**  
    Documento contendo todos os bugs identificados.

- **Relatorio_de_Teste.md**
  Relatório com notas da seções, sugestões, evidências e conclusões.

## Ferramentas Utilizadas

- Navegador Google Chrome (Windows 10)  
- VS Code para edição dos documentos  
- Xbox Game Bar e Spinning Tool- Captura e Gravação de tela.


## Sobre

Este projeto foi realizado como parte do meu portfólio profissional na área de QA Manual, com foco em testes exploratórios e documentação de qualidade.
